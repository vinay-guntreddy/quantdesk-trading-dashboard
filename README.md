# QuantDesk — Trading Dashboard

QuantDesk is a web-based trading dashboard built with React, TypeScript, and Vite. It provides a visual interface for exploring market-style data and trading information.

## Features

- Interactive trading dashboard interface
- Market-style data visualization
- Reusable React components
- Responsive layout
- Simulated market data for demonstration purposes

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Run Locally

**Requirements:** Node.js and npm.

```bash
git clone https://github.com/vinay-guntreddy/quantdesk-trading-dashboard.git
cd quantdesk-trading-dashboard
npm install
npm run dev
```

Open the local URL printed in your terminal.
